## Contributing

If you'd like to contribute to the documentation, please follow these guidelines:

1. Place API documentation in the `docs/api` directory.
2. Place feature-specific documentation in the `docs/features` directory.
3. Place database-related documentation in the appropriate database directory (e.g., `docs/timescaledb`).
4. Use Markdown for all documentation files.
5. Include code examples where appropriate.
6. Keep documentation up-to-date with code changes.
